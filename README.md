# VV Pulse

VV Pulse is the field operations and real-world signal layer of the VV Hybrid Universe.

## What It Is

VV Pulse is built around human validation, missions and live field presence.

It is designed to connect digital systems with verified activity in the real world.

## Why It Exists

The VV Hybrid Universe is not meant to rely only on screens and abstract data.

VV Pulse exists to bring:

- missions
- verified presence
- human confirmation
- location-based activity

into the wider ecosystem.

## Repository Scope

This repository currently contains the standalone VV Pulse web surface, including:

- `index.html`
- `vv-pulse.js`
- `style.css`
